# Paya's Terrible Additions

A content mod that adds whatever its authors wanted to see in Balatro.

## Content

- 80+ new Jokers
- New consumables, both of existing and new types
- New vouchers, blinds, boosters, tags and decks
- New card modifiers
- New mechanics
- Cross-mod content, for example with Cryptid

## Requirements

- Steamodded 1.0.0~BETA-0822d or newer
- Balatro 1.0.1o or newer
- Talisman is optional; some effects use it when installed

## Good to know

- **No longer maintained:** the repository is archived. This entry is pinned to the last release (0.99.2-alpha), so it may break with newer Steamodded versions.
- Declared conflicts: Entropy before 1.0 and MoreFluff before 1.2.0. Not compatible with Jen's Almanac.
- One Joker plays text-to-speech. It sends the spoken text to a third-party server (tts.cyzon.us) over an unencrypted connection.
